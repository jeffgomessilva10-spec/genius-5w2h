## 3. GERENCIANDO PROJETOS

### ➕ Como criar um projeto

```
1️⃣  Clique em "Projetos" no menu lateral
2️⃣  Clique no botão "+ Novo Projeto" (canto superior direito)

3️⃣  Preencha o formulário:
    ┌─────────────────────────────────────┐
    │ Nome do projeto *                   │
    │ [Planejamento Estratégico 2026    ] │
    │                                     │
    │ Descrição                           │
    │ [Projeto para definir e executar  ] │
    │ [as metas anuais da empresa       ] │
    │                                     │
    │ Data de início    Data de término   │
    │ [01/01/2026    ]  [31/12/2026    ] │
    └─────────────────────────────────────┘

4️⃣  Clique em "Criar Projeto" ✅
```

### 👥 Como adicionar membros ao projeto

Membros são as pessoas que poderão ver e trabalhar no projeto.

```
1️⃣  Na tela de Projetos, localize o seu projeto
2️⃣  Clique no botão "Gerenciar membros"
3️⃣  Você verá a lista de membros atuais e os disponíveis
4️⃣  Clique no nome do usuário que deseja adicionar
5️⃣  Clique em "Adicionar" ✅

Para REMOVER um membro:
    Clique no ✕ vermelho ao lado do nome do membro
```

> ⚠️ **Atenção:** Colaboradores só veem projetos em que foram adicionados. Clientes só veem os indicadores do projeto em que foram vinculados.

### 🔍 Acessando os detalhes de um projeto

```
1️⃣  Clique em "Projetos" no menu
2️⃣  Clique na seta "Ver projeto →" no card do projeto
    OU clique no nome do projeto

Você verá:
  • Todas as categorias e atividades organizadas
  • Linha do tempo visual
  • Membros vinculados
```

## 4. ATIVIDADES 5W2H

### 🧩 O que é o 5W2H?

É uma metodologia simples e poderosa que garante que toda tarefa tenha todas as informações necessárias. Responde 7 perguntas essenciais:

```
┌─────────────────────────────────────────────────────────┐
│                   METODOLOGIA 5W2H                      │
├─────────────┬───────────────────────────────────────────┤
│  O QUÊ?    │ O que será feito? Qual a entrega?         │
│  (What)    │ Ex: "Redesign completo do site"           │
├─────────────┼───────────────────────────────────────────┤
│  POR QUÊ?  │ Por que é necessário? Qual o benefício?  │
│  (Why)     │ Ex: "Aumentar conversões em 30%"         │
├─────────────┼───────────────────────────────────────────┤
│  QUEM?     │ Quem é o responsável pela execução?      │
│  (Who)     │ Ex: "Equipe de Design + Agência XYZ"     │
├─────────────┼───────────────────────────────────────────┤
│  ONDE?     │ Onde será executado? Qual o ambiente?    │
│  (Where)   │ Ex: "Servidor de staging + produção"     │
├─────────────┼───────────────────────────────────────────┤
│  COMO?     │ Como será feito? Qual a metodologia?     │
│  (How)     │ Ex: "Sprint de 3 semanas: wireframe →    │
│            │      protótipo → aprovação → código"     │
├─────────────┼───────────────────────────────────────────┤
│  QUANTO?   │ Qual o custo estimado? (R$)              │
│  (How Much)│ Ex: R$ 8.500,00                          │
├─────────────┼───────────────────────────────────────────┤
│  QUANDO?   │ Qual o prazo? Data de início e fim.      │
│  (When)    │ Ex: 01/02/2026 até 31/03/2026            │
└─────────────┴───────────────────────────────────────────┘
```

### ➕ Como criar uma nova atividade

```
1️⃣  Clique em "+ Nova Atividade" (canto superior direito do Dashboard)

2️⃣  Preencha o formulário 5W2H:

    IDENTIFICAÇÃO
    ┌────────────────────────────────┐
    │ Código: [1.1]  Categoria: [Site▼]
    │ Responsável: [Jefferson Silva ▼]
    └────────────────────────────────┘

    5W2H
    ┌────────────────────────────────┐
    │ O Quê *                        │
    │ [Redesign do site institucional]│
    │                                │
    │ Por Quê *                      │
    │ [Aumentar conversão de leads   ]│
    │                                │
    │ Quem *                         │
    │ [Equipe de Design              ]│
    │                                │
    │ Onde *                         │
    │ [Servidor AWS - ambiente produção]
    │                                │
    │ Como *                         │
    │ [Redesign completo com Figma   ]│
    │ [+ desenvolvimento React       ]│
    └────────────────────────────────┘

    FINANCEIRO E DATAS
    ┌────────────────────────────────┐
    │ Custo estimado (R$): [8500   ] │
    │ Horas planejadas:    [120    ] │
    │ Data início: [01/02/2026     ] │
    │ Data fim:    [31/03/2026     ] │
    └────────────────────────────────┘

    STATUS
    ┌────────────────────────────────┐
    │ Status: [Em andamento        ▼]│
    └────────────────────────────────┘

3️⃣  Clique em "Salvar" ✅
```

### ✏️ Como editar uma atividade

```
1️⃣  Localize a atividade no Dashboard ou na lista
2️⃣  Clique no ícone ✏️ (lápis)
3️⃣  Faça as alterações necessárias
4️⃣  Clique em "Salvar" ✅

⚠️ Ao mudar o STATUS, todos os envolvidos receberão
   notificação automática por e-mail!
```

### 🔄 Status das Atividades

```
PLANEJADO → EM ANDAMENTO → FINALIZADO
                ↓
            ATRASADO (automático quando passa do prazo)
```

| Status | Quando usar |
|---|---|
| **PLANEJADO** | Tarefa ainda não iniciada, aguardando início |
| **EM ANDAMENTO** | Trabalho sendo executado atualmente |
| **ATRASADO** | Prazo passou sem conclusão (também automático pelo sistema) |
| **FINALIZADO** | Tarefa 100% concluída e entregue |

### ⚠️ Matriz de Riscos

Ao criar ou editar uma atividade, você pode definir o risco:

```
PROBABILIDADE (1 a 5):        IMPACTO (1 a 5):
1 = Muito improvável    ×     1 = Desprezível
2 = Pouco provável      ×     2 = Menor
3 = Provável            ×     3 = Moderado
4 = Muito provável      ×     4 = Significativo
5 = Praticamente certo  ×     5 = Catastrófico

O SISTEMA CALCULA AUTOMATICAMENTE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Score 1-5   → 🟢 BAIXO
Score 6-11  → 🟡 MÉDIO
Score 12-19 → 🟠 ALTO
Score 20-25 → 🔴 CRÍTICO
```

**Exemplo prático:**
- Probabilidade 4 × Impacto 4 = Score 16 → 🟠 ALTO

Preencha também o **Plano de Mitigação**: o que faremos para reduzir/evitar o risco?

### 🤖 Validação com IA

O sistema possui um validador inteligente que analisa a qualidade dos campos:

```
1️⃣  No formulário de atividade, clique em "Validar com IA"
2️⃣  O sistema analisa cada campo e dá uma nota:

    Nota A (90-100%): ✅ Excelente
    Nota B (70-89%):  📋 Bom
    Nota C (50-69%):  ⚠️ Regular
    Nota D (<50%):    ❌ Insuficiente

3️⃣  Você verá sugestões de melhoria para cada campo
```

### 💬 Comentários na Atividade

Cada atividade tem uma seção de comentários para troca de informações:


## 5. CRONOGRAMA GANTT

O Gantt é o gráfico de barras horizontais que mostra todas as atividades no tempo. É a forma mais visual de acompanhar o progresso!

### 🗓️ Como acessar

```
Clique em "Gantt" no menu lateral
```

### 📊 Como ler o gráfico

```
NOME DA ATIVIDADE    JAN        FEV        MAR        ABR
─────────────────────────────────────────────────────────
1.1 Redesign site    ████████████████
1.2 SEO on-page                    ████████████
2.1 Calendário edit. ██████████████████████████████████
5.1 Funil de vendas           ██████████████
                               ↑
                            HOJE (linha vermelha)
```

- **Cada linha** = uma atividade
- **O comprimento da barra** = duração (do início ao fim)
- **A cor da barra** = status da atividade
- **A linha vermelha** = data de hoje
- **Passe o mouse sobre uma barra** = veja todos os detalhes

### 🔍 Usando os Filtros

#### Filtro de Período (acima do Gantt)

```
┌────────┬────────┬─────────┬────────┐
│ Todos  │  Hoje  │ Semana  │  Mês   │
└────────┴────────┴─────────┴────────┘
    ↑ Selecione um período para filtrar as atividades exibidas

TODOS:   Mostra todas as atividades com datas cadastradas
HOJE:    Atividades com início ou fim na data de hoje
SEMANA:  Atividades da semana atual (segunda a domingo)
MÊS:     Atividades do mês atual (dia 1 ao último dia)
```

#### Filtro de Status (abaixo do período)

```
┌──────────────┬───────────────┬─────────────┬──────────────┐
│⚫ Planejadas │🔵 Em andamento│🔴 Atrasadas │✅ Concluídas │
│     21       │      42       │     64      │      1       │
└──────────────┴───────────────┴─────────────┴──────────────┘

• Clique em um status para filtrar APENAS aquele status
• Clique novamente para DESMARCAR o filtro
• Você pode selecionar MÚLTIPLOS status ao mesmo tempo
• O número dentro de cada botão mostra a quantidade
• Clique em "✕ Limpar" para remover todos os filtros
```

#### Filtro por Projeto

```
Use o menu no canto superior direito para ver
as atividades de um projeto específico.
```

> 💡 **Dica:** Os KPIs acima do Gantt se atualizam automaticamente quando você muda os filtros. Clique em qualquer card de status para filtrar rapidamente!

## 8. OKRs

OKR significa **Objectives and Key Results** (Objetivos e Resultados-Chave). É uma forma de definir metas ambiciosas e medir o progresso de forma clara.

### 🎯 Como funciona?

```
OBJETIVO: "O que queremos alcançar?"
  Exemplo: "Aumentar a presença digital da empresa"
  
  └── RESULTADO-CHAVE 1: "Seguidores Instagram"
      Meta: 10.000  │  Atual: 6.500  │  65% ✅
      
  └── RESULTADO-CHAVE 2: "Taxa de conversão site"
      Meta: 5%  │  Atual: 2.1%  │  42% ⚠️
      
  └── RESULTADO-CHAVE 3: "Leads gerados por mês"
      Meta: 200  │  Atual: 45  │  22% ❌

PROGRESSO DO OBJETIVO: (65% + 42% + 22%) ÷ 3 = 43% ⚠️
```

### ➕ Como criar um Objetivo

```
1️⃣  Clique em "OKRs" no menu lateral
2️⃣  Clique em "+ Novo Objetivo"
3️⃣  Preencha:
     - PROJETO: Qual projeto este objetivo pertence
     - TÍTULO: O que queremos alcançar
     - DESCRIÇÃO: Contexto e importância
     - PRAZO: Data limite para atingir o objetivo
4️⃣  Clique em "Criar Objetivo" ✅
```

## 9. PDCA E LIÇÕES APRENDIDAS

### 🔄 O Ciclo PDCA

O PDCA é um ciclo de melhoria contínua que ajuda sua equipe a aprender com cada projeto:

```
        ┌──────────────┐
        │   P — PLAN   │ ← Planejar: o que faremos?
        │  (Planejar)  │   Quais os objetivos e processos?
        └──────┬───────┘
               │
               ▼
┌──────────────┐        ┌──────────────┐
│  A — ACT     │        │   D — DO     │
│   (Agir)     │        │  (Executar)  │
│ Padronizar   │        │ Implementar  │
│ ou corrigir  │        │ o plano      │
└──────┬───────┘        └──────┬───────┘
       │                       │
       │    ┌──────────────┐   │
       └────│  C — CHECK   │◄──┘
            │  (Verificar) │
            │ Monitorar e  │
            │ medir result │
            └──────────────┘
```

### ➕ Como registrar uma revisão PDCA

```
1️⃣  Clique em "PDCA" no menu lateral
2️⃣  Certifique-se que está na aba "Ciclo PDCA"
3️⃣  Clique em "+ Novo Registro"
4️⃣  Preencha:
     - PROJETO: Qual projeto
     - FASE: Selecione P, D, C ou A
     - TÍTULO: Nome desta revisão
     - DESCRIÇÃO: O que foi feito/observado
     - ITENS DE AÇÃO: Próximos passos
5️⃣  Clique em "Salvar" ✅
```

### 📚 Como registrar uma Lição Aprendida

Lições aprendidas são o conhecimento que guardamos para projetos futuros.

```
1️⃣  Clique em "PDCA" no menu lateral
2️⃣  Clique na aba "Lições Aprendidas"
3️⃣  Clique em "+ Nova Lição"
4️⃣  Preencha:
     - PROJETO: Qual projeto
     - CATEGORIA: Geral, Técnico, Processo, Equipe...
     - TÍTULO: Nome da lição
     - O QUE ACONTECEU: Descreva a situação
     - IMPACTO: Qual foi o efeito?
     - RECOMENDAÇÃO: O que fazer diferente da próxima vez?
5️⃣  Clique em "Salvar" ✅
```

> 💡 **Dica:** Registre lições aprendidas ao final de cada fase importante do projeto, não só no encerramento. O conhecimento fresco é mais rico!

## 13. PERGUNTAS FREQUENTES

### ❓ Não consigo fazer login. O que faço?

```
1. Verifique se o e-mail está correto (cuidado com espaços)
2. Verifique se a senha está correta (cuidado com Caps Lock)
3. Se esqueceu a senha, peça ao Administrador para redefinir
4. Se o erro persistir, entre em contato com o suporte
```

### ❓ Não estou recebendo e-mails de notificação

```
1. Verifique a pasta de SPAM/Lixo eletrônico
2. Adicione o remetente "Genius Consultoria" como contato
3. Se nada aparecer, fale com o Administrador para
   verificar as configurações de e-mail do sistema
```

### ❓ Uma atividade ficou como ATRASADA mas já concluímos

```
1. Clique no ícone ✏️ (editar) da atividade
2. Altere o Status para "FINALIZADO"
3. Clique em "Salvar"
   → Todos os envolvidos receberão notificação automática
```

### ❓ Não consigo ver um projeto

```
Você só vê projetos em que foi ADICIONADO.
→ Peça ao Administrador para te adicionar ao projeto desejado
```

### ❓ O Gantt não mostra minhas atividades

```
O Gantt exibe APENAS atividades que têm:
  ✅ DATA DE INÍCIO preenchida  E
  ✅ DATA DE TÉRMINO preenchida

Verifique se as atividades têm os dois campos preenchidos.
Se não tiver, edite a atividade e adicione as datas.
```

### ❓ Posso exportar os dados para Excel/PDF?

```
Atualmente o sistema não possui exportação automática.
Os dados podem ser:
  • Visualizados e copiados manualmente das telas
  • Solicitados ao Administrador do sistema para extração
    do banco de dados
```

### ❓ Como vejo quem está responsável por cada atividade?

```
No Dashboard: cada card de atividade mostra o responsável
No Gantt: passe o mouse sobre a barra para ver os detalhes
Na lista de atividades: a coluna "Quem" mostra o responsável
```

### ❓ Posso ter mais de um responsável por atividade?

```
O campo "Quem" é textual e pode ter múltiplos nomes.
Para controle formal de responsabilidades, use a
MATRIZ RACI (disponível nos detalhes de cada atividade):
  R = Responsible (executa)
  A = Accountable (responsável final)
  C = Consulted (consultado)
  I = Informed (informado)
```

### ❓ Como acompanho o progresso financeiro?

```
Dashboard Operacional:
  → Seção "Financeiro — Minhas Atividades"
  → Mostra: Previsto vs Realizado

Dashboard Executivo:
  → Cards "Orçamento total" e "Em risco"
  → Tabela de projetos com CPI e variação de custo

Atividade individual:
  → Campo "Custo realizado" (atualizado pela equipe)
  → Campo "Horas realizadas" (calculado pelos apontamentos)
```
